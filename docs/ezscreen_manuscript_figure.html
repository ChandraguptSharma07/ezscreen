End-to-End Architecture

A researcher provides a target and ligand library. ezscreen then performs receptor preparation, pocket selection, ligand preparation, optional filtering, GPU docking on Kaggle, checkpointed result recovery, and post-docking interpretation in one continuous pipeline.

Inputs

Researcher provides target and chemical library

Entry can begin with a PDB structure, an AlphaFold model, a PDB code, and a ligand set from files, fetched libraries, or sketched molecules.

Why This Is Distinct

Free cloud GPU as the default compute layer

The key architectural decision is that docking runs on Kaggle GPU notebooks, so the tool removes the local GPU or institutional HPC requirement for the end user.

Full pipeline, not just remote docking

ezscreen does not merely submit jobs. It handles receptor preparation, ligand preparation, pocketing, triage, orchestration, resume, validation, and final interpretation in one system.

Reporting artifacts built into the workflow

The workflow ends in figures, tables, interaction views, and methods text that support review and manuscript drafting, but they are not a substitute for external validation.
